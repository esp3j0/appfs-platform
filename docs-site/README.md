# AppFS 平台文档站（Docusaurus）

基于 [Docusaurus 3](https://docusaurus.io/) 的教学与参考文档站。**简体中文为默认语言**，英文为第二语言（增量翻译中）。

内容按 [Diátaxis](https://diataxis.fr/) 四象限组织，每个象限是一个独立侧边栏：

| 象限 | 目录 | 读者目的 | 目录约定 |
|---|---|---|---|
| 🎓 教程 Tutorials | `docs/tutorials/` | 学会一件事 | 线性、可复现、能跑通 |
| 🛠️ 实操指南 How-to | `docs/how-to/` | 解决具体问题 | 目标导向的步骤清单 |
| 📚 参考 Reference | `docs/reference/` | 查阅字段/契约 | 面向查阅，不面向阅读 |
| 💡 原理 Explanation | `docs/explanation/` | 理解设计动机 | 权衡与历史，不面向操作 |

教程象限下分两条学习路径：**应用开发者路径**（`tutorials/user/`）与**项目贡献者路径**（`tutorials/contributor/`）。

## 快速开始

```bash
cd docs-site
npm install
npm run start          # 开发服务器（热更新），默认 http://localhost:3000
npm run build          # 生产构建到 build/
npm run serve          # 本地预览构建产物
```

要求 Node.js ≥ 20。

## 预览不同语言

- 默认（简体中文）：`npm run start`
- 英文：`npm run start -- --locale en`
- 构建英文：`npm run build -- --locale en`

`npm run build` 默认只构建默认语言；多语言部署见 [Docusaurus i18n 部署文档](https://docusaurus.io/docs/i18n/deployment)。


## 如何新增一篇文档

1. 选对象限：先问读者目的（学？做？查？懂？），别把教程和参考混在一起。
2. 在对应目录新建 `slug.md`（文件名即 URL slug，**不要带数字前缀**）。阅读顺序用 front matter 的 `sidebar_position`（如 `sidebar_position: 2`），落地页用 `sidebar_position: 0`。
   - ⚠️ 坑：Docusaurus 会把文件名开头的 `NN-` 数字前缀**从 URL 剥离**（只用于排序）。若用前缀命名，站内链接很容易对不上，故本站统一用 `sidebar_position` 排序、文件名不带前缀。
3. 顶部 front matter 至少含 `title` 与 `description`。
4. 跨站内链接用相对路径（如 `../../reference/action-contract`）。本站文件名无前缀，故相对路径即为最终 URL。
5. 指向**仓库内、但不在本 docs 站内**的权威文件（如 `docs/agent-lifecycle-architecture.md`）时，**用行内代码路径而非超链接**——否则会被 broken-link 检查判为死链。

## 如何翻译

```bash
# 1. 重新生成界面字符串骨架（会更新 code.json）
npm run write-translations -- --locale en

# 2. 把对应文档的中文文件复制到英文目录并翻译
#    docs/tutorials/index.md
#  → i18n/en/docusaurus-plugin-content-docs/current/tutorials/index.md
```

翻译约定：英文文件路径须与 `docs/` 下源文件一一对应；翻译文件缺失时该页在英文 locale 不显示（增量翻译时这是预期行为）。

## 从现有文档迁移（映射表）

仓库里已有大量权威 Markdown，散落在各处。本站**不复制**它们，而是把教学/参考内容重写进四象限，并在每页末尾用行内代码指向**权威来源**。现有文档的归属建议：

| 现有文件 | 建议落到 |
|---|---|
| `CLAUDE.md`（根）"Architecture" / "Mount Contract" | 教程（contributor 路径）、参考（action-contract）的权威来源 |
| `docs/agent-lifecycle-architecture.md` | 教程（principal-lifecycle）+ 原理（principal-attach-design）的来源 |
| `docs/adr/0001-monorepo-layout.md`、`0002-repo-workflow.md` | 原理（two-layer-separation） |
| `appfs/MANUAL.md` | 参考 + 教程（mount）命令来源 |
| `appfs/docs/v4/*`、`appfs/examples/appfs/ADAPTER-QUICKSTART.zh-CN.md` | 教程（write-connector）+ 参考 |
| `integration/APPFS-appfs-agent-attach-contract-v1.1.md` | 参考（action-contract）来源 |
| `docs/plans/*`（设计/实现计划） | 原理（设计动机）的素材，不是直接教学内容 |
| `appfs/sdk/{rust,typescript,python,go}/README.md` | 教程（first-message）多语言示例的来源 |
